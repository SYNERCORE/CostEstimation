+ New Request
Logs the request in CE Monitoring, assigns it, and sends whatever came with it. The estimator Loads it, builds the estimate, and Saves under the same number.
CancelLog request & send 3 file(s)
The picker is new. Multiple files, each listed with its size, each removable with ✕ before you commit. Picking again adds to the list rather than replacing it, and the same file picked twice is only sent once.
The button counts. With nothing attached it reads simply Log request. It only promises files when there are files.
Nothing goes up until the request is saved — there is no row to hang an attachment on until then. The files are held on the form, the request is logged, its Monitoring row is written, and only then are they sent.
The attachments panel still opens afterwards, so anything that arrives later goes in there from the 📎 button, exactly as before.
